# 灵框 LingKuang · 功能路线图（ROADMAP）

> 愿景与待办。优先做"核心体验"相关的；标注了建议的拆分方式，方便 AI 助手按小步实现。

## 已实现（v3 当前）

- [x] 世界观时间线（横向节点图、多时间线、多条循环、节点关联人物/地点）
- [x] 随机角色生成器（词条锁定、数量选择、组合存档）
- [x] 词义联想图（力导向、单线聚焦、选中支线保留、暂存词导出）
- [x] Markdown 编辑器（双栏预览）
- [x] MCP server（查询世界观）
- [x] AI 联想双模式（本地 Ollama / OpenAI 兼容 API）
- [x] 打包发布（NSIS 安装版 + 便携版）

## 近期（P1 · 核心体验）

### 1. 编辑器增强（v3 待办主线）
- [ ] 文稿 ↔ 时间线联动：节点可关联文稿，点击跳转
- [ ] 富媒体支持：图片 / 音乐 / 3D 模型 放入文稿（向"富媒体叙事编辑器"演进）
- [ ] 分镜用途：图片序列 + 音效 → 分镜草稿

### 2. 时间线进阶
- [ ] **剧情范围框定**：时间线标剧情起点/终点，默认聚焦剧情范围，世界历史作为折叠背景层
- [ ] **事件因果引导线**：节点之间画引导线表示因果/关联（DAG 可视化），不只时间先后
- [ ] **多分支时间线**：分支（抉择线/平行世界）+ 合并（类 git branch → merge）
- [ ] **分支程序化生成**：用规则/函数描述分支形态（L-system / IFS 思路），按需惰性展开

### 3. 角色系统
- [ ] **角色状态版本化（类 git）**：角色重大改变创建版本节点，按时间段查询角色介绍（Event Sourcing + 快照）
- [ ] **角色改变强调显示**：重大改变节点高亮，时间越久强调度越低（新鲜度衰减）
- [ ] **隐式建模 + 变更描述**：存"初始状态 + 变更描述"（差分），任意时间点可查询（数据层隐式、视图层显式展开）

### 4. 词义联想增强
- [ ] 联想结果缓存（localStorage 或 SQLite）
- [ ] **SQLite 关联图**（`associations.db`，words + associations 双向表）：词库到 5 万词规模时的持久化方案（当前 localStorage 暂存够用，YAGNI）
- [ ] 暂存词导出增强：分类预览确认（当前自动分类 ~80% 准确）

## 远期（P2 · 发布级功能完整性）

### 5. 多视角叙事
- [ ] **事件多视角**：同一事件不同角色视角的版本，切换查看
- [ ] **AI 补写多视角**：根据世界视角描述 + 角色画像 → 自动生成角色视角草稿（复用 MCP + LLM 链路；AI 草稿需人审）

### 6. 素材与扩展
- [ ] **素材嗅探**：联想图抽词 → 搜索引擎搜对应参考图（原定暂缓）
- [ ] 插件化工具系统（灵框 v3 愿景：内置可调用工具）

### 7. 分发与运维
- [ ] 自动更新（electron-updater + GitHub Releases）
- [ ] 代码签名（消除 SmartScreen 警告）
- [ ] macOS / Linux 支持（打包目标 + 平台适配）
- [ ] 词库合规：自建/替换萌百词库（商用场景必需）

## 完成顺序建议

1. 先修 `docs/BUGS.md` 里打勾靠前的（时间线多循环、联想图分类）
2. 再做 P1 里"编辑器增强"（v3 主线，用户自己要用）
3. 时间线进阶的 ①②③ 是世界观创作的核心竞争力
4. 角色版本化是灵框区别于普通时间线工具的差异化功能

> 每个功能建议拆成小步：数据模型 → 渲染 → 交互 → 持久化 → 测试，方便 AI 分步实现。
